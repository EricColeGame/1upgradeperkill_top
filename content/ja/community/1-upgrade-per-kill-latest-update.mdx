## アップグレードラダー：Leather から MAXED までの8ステップ

ラダーこそがゲームのすべてだ。ページには進行度が Leather → Copper → Iron → Full Diamond → Ruby → Shadow → Prism → MAXED と記載されている。これは8つの独立した段階であり、最上位に到達するには7連続キルが必要——そして1回の死でそのすべてを失う。

| ティア | 段階 | 実際に意味すること |
|---|---|---|
| Leather | 0キル | 初期スポーン装備。大半のデュエルで負けると思ってよい |
| Copper | 1キル | わずかなバッファー。Iron 以上相手にはまだ脆い |
| Iron | 2キル | 打ち合って生き残れる最初のティア |
| Full Diamond | 3キル | 多くのプレイヤーが目指す「本物の鎧」のマイルストーン |
| Ruby | 4キル | スノーボール領域。デフォルトで勝ち始める |
| Shadow | 5キル | 高価値ターゲット——全員があなたの連勝を狙う |
| Prism | 6キル | 天井まであと1戦 |
| MAXED | 7キル以上 | 完全強化。あなたがロビーのボス戦になる |

このデザインが美しいのは、通常の PvP のインセンティブを反転させている点だ。ほとんどのアリーナゲームでは、最強のプレイヤーは常に戦いたがる。ここでは、最強のプレイヤーは*慎重に*戦いたがる。Full Diamond を超えた瞬間にリスクとリワードの曲線が反転するからだ。

プレイヤー体験によれば、実用的なスイートスポットは Diamond から Ruby だ。そのティアなら低装備の相手にはほとんどのマッチアップで勝てるが、ボーナス XP を狙う全員にとっての灯台のように輝いてはいない。Shadow を超えて押し進むと連勝が死ぬことが多い——装備が悪くなるからではなく、ロビー全体があなたに対して連携し始めるからだ。

| クラス | プレイスタイル（コミュニティの説明） | 向いている人 |

| Archer | 遠距離からのチップダメージと逃げる相手の始末 | 高ティアのターゲットを狙う人 |
| Trickster | 機動力とミスディレクション | 不利な戦闘からの離脱 |

実用的な注意点が2つある。1つ目は、これがフリーフォーオールなのでヒーラーもタンクロールも存在しないこと——すべてのクラスが自分自身の生存問題を解決しなければならない。2つ目は、ラダー上の位置に応じてクラス選択を変えるべきだということ。Scorcher のような攻撃的な選択は、失うものがない Leather や Copper では素晴らしいが、1回のオーバーエクステンションでラン全体を失う Prism では恐ろしい。

まったくの初心者なら、Warrior か Skirmisher から始めよう。トラップやバーンスタックを同時に管理することを求めずに、間合いとノックバックのタイミングを教えてくれる。

## ギアセーバー、エンチャント、クレート、その他の進行システム

1 Upgrade Per Kill 最新アップデートでも、ラダーの上に乗るメタシステム層は同じままだ。これらはランをまたいで持続し、残酷なリセットの後でもキューに並び続ける理由を与えてくれるものだ。

| システム | 何をするか | 新規プレイヤーへの優先度 |
|---|---|---|
| Gear Saver | 高アップグレードで死んだ後も鎧を保持できるとされる | 最高——最高のランを守る |
| Gold | プレイで獲得し、パークに使う通貨 | 高——安定したパッシブ価値 |
| Perks | Gold で買えるアップグレード | 高 |
| Enchants | 装備に適用されるランダム修正 | 中——運依存 |
| Crates | ランダム報酬 | 中 |
| Capes | コスメコレクション | 低（見た目が気になる場合を除く） |

Gear Saver はゲーム内で最も誤解されているアイテムだ。新規プレイヤーは溜め込んで使わない。経験者はまさに適切な瞬間に焚べる。コミュニティの報告から導かれる一般則はこうだ。Diamond 未満で Gear Saver を使わないこと、そして Archer だらけのロビーで Prism の連勝を抱えているときに「後で使う」ために取っておかないこと。保険は使うために存在する。

Gold とパークこそが長期的な進捗の住処だ。死亡時に鎧はリセットされるため、Gold はセッションがどれだけひどくても蓄積し続ける唯一のものになる。だからこそパーク購入は、このゲームにおける永久パワーカーブに最も近い存在なのだ。

## リーダーボードと高アップグレードプレイヤー狩りの極意

ゲームページには3つのリーダーボードが記載されている。Best Streak、Top Kills、Fastest Diamond だ。これらはまったく異なる3つのプレイスタイルに報いるもので、単一のキルカウンターより賢い設計だ。

| リーダーボード | 何を測るか | 登り方 |
|---|---|---|
| Best Streak | 死なずに続けた最長ラン | Shadow ティア以上では受け身に立ち回る |
| Top Kills | 累計またはシーズンのキル数 | 低ティアで常に戦う |
| Fastest Diamond | スポーンから Full Diamond までの速度 | 序盤に人の多いエリアをスポーンキャンプ |

最も過小評価されているのは Fastest Diamond ボードだ。最初の3キルの生の攻撃性に報いるもので、まさに失うものが最も少ない瞬間を狙っている。これを追うなら、Diamond を超えてアップグレードする必要はない——リセットしてまた行こう。

さらにバウンティシステムもある。高アップグレードのプレイヤーを狩るとボーナス XP が得られる。このメカニクスのせいで Prism や MAXED のプレイヤーはくつろげない。ラダーの頂点に立った瞬間、あなたはプレイヤーであることをやめ、公共のイベントになる。賢い高ティアのプレイヤーはアリーナの端へローテートして開けた視線を避け、賢い低ティアのプレイヤーは中央をパトロールして光る誰かが通り過ぎるのを待つ。

## より速く登るための実践的なコツ

- **3キル目は慎重に貯めよう。** Full Diamond は狩る価値がある存在になる変曲点だ。次の2戦は守備的に戦おう。
- **ノックバックを覚えよう。** ゲームはクリティカル、ノックバック、本物の鎧を売りにしている。リングアウトや端からの押し出しは、純粋なダメージよりも多くのプレイヤーを殺す。
- **ティアに応じてクラスを入れ替えよう。** 序盤は攻撃的な選択、終盤は回避的な選択。
- **WELCOME コードを使おう。** ゲームページに無料ギフトとして記載されており、Block PvP グループも無料報酬の第2の入手元として挙げられている。
- **Shadow を超えて逃げる相手を追うな。** 傷ついたプレイヤーが後退するのは、たいていあなたを第三者との戦いに誘い込むための餌だ。
- **パッチ後1時間ではなく、パッチ翌日にプレイしよう。** テスターがログオフした後のロビーはより柔らかい。
