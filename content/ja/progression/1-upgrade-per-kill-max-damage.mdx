## 1 Upgrade Per Kill のループの仕組み

1キルで1ティア。1デスでゼロに戻る。**1 Upgrade Per Kill** はこのたった一つのルールだけで作られた Roblox のフリーフォーオール・アリーナであり、PvP への向き合い方そのものを組み替えてしまいます。戦うたびにテンポと生存のトレードオフが発生し、ギアが強くなるほど失うものが増え、ロビーの他の全員があなたからそれを奪いたいと思うようになります。動作環境は[Roblox 公式プラットフォーム](https://www.roblox.com/)なので、すでに持っているクライアント以外にインストールするものはありません。

**1 Upgrade Per Kill 最大ダメージ**の構成を探しているなら、まず正しいメンタルモデルから始めましょう。ダメージは時間をかけて積み上げるステータスではありません。はしごの頂点に到達するまで生き延び、その後サーバー全員に狙われながらその位置を維持した者への報酬です。

この設計は、アリーナがなぜこれほど緊張感を帯びるのかも説明してくれます。レザーのプレイヤーは守るものがなく、得るものだけがあるので、無茶な戦いを仕掛けて時には勝ってしまいます。プリズムのプレイヤーは一つの命にラン全体を賭けており、欲張った追撃一回で20分の働きが消え去ることもあります。この非対称性を理解し、他のプレイヤーに対して利用することこそが、このゲームの本当のスキル上限です。

| ランの段階 | 主な優先事項 | ラン最大の脅威 |
|---|---|---|
| 序盤（レザー → カッパー） | 安全なキルを稼ぎ、スポーン位置の流れを覚える | 装備が整わないうちに漁夫の利を狙われる |
| 中盤（アイアン → フルダイヤモンド） | ギアをマップ支配に変換する | 逃げる相手を開けた場所まで追いかけすぎる |
| 高盤（ルビー → シャドウ） | 何よりも連勝を守る | 連携したデュオとボーナスXP狙いのハンター |
| 頂点（プリズム → MAXED） | まず生き残り、稼ぎは二の次 | リスポーン直後の相手とのプライド勝負 |

## ギア階層をティアごとに解説

ゲーム自身の説明では8段階が示されています：レザー、カッパー、アイアン、フルダイヤモンド、ルビー、シャドウ、プリズム、MAXED。キルするたびにちょうど1段上がり、死ぬたびにレザーまで戻されます。説明文にはティアごとの正確なステータス値は公開されていないため、下の表では各ティアをダメージ表ではなく「役割」として扱っています。それが誠実な計画の立て方です。

| ティア | ラン内での位置づけ | 立ち回り方 |
|---|---|---|
| レザー | すべてのランのスタート地点 | 受け身でプレイし、他人の戦いの後始末を拾い、開けた通路を避ける |
| カッパー | 最初のアップグレード | まだ脆い — どのデュエルもほぼコイントスだと思って扱う |
| アイアン | はしごの中段 | 打ち合えるだけのギアがある。戦いを受けるのではなく選び始める |
| フルダイヤモンド | 定番のチェックポイント | もう狙う価値のある存在。遮蔽物を使って動き、集団に注意する |
| ルビー | ダイヤモンドの上 | 攻めるほど報われるが、撤退ルートがある場合に限る |
| シャドウ | 高ティア | ボーナスXP狙いのハンターに狙われる前提で動く。1対2は断る |
| プリズム | 頂点間近 | キルより生存を優先。他人に戦わせる |
| MAXED | はしごの頂点 | 全員があなたの連勝を狙う。ロビー全体が狩ってくるつもりで戦う。実際そうだから |

正しい行動が途中で反転する点に注目してください。フルダイヤモンド未満では失うものが少ないので、積極的に戦いを探すべきです。ルビー以上では計算が逆転します。キルを重ねるたびに得られるのは1段ですが、死ねばはしご全体を失います。だからこそ腕の立つ **1 Upgrade Per Kill** プレイヤーはランの終盤に静かになり、ロビーが自然に淘汰されるのを待つのです。

## 1 Upgrade Per Kill 最大ダメージを追い求める

「最大ダメージ」という言葉は、ダメージ表の頂点に立つ単一のビルドが存在するかのように語られます。しかし実際のところ、あなたの実効ダメージ出力は複数の要素が噛み合って生まれる積であり、そのどれもランの開始時に丸ごと買えるものではありません。

- **ティア位置。** 上位のアーマーティアはクリティカルやノックバックが機能する本物のアーマーと説明されているため、はしごを上るほどヒットが実際の撃破につながりやすくなります。
- **クラス選択。** 近接クラスと遠距離クラスではプレッシャーのかけ方がまったく異なります。エイムと反応速度に合ったものを選ぶことが、生のステータスより重要です。
- **エンチャントロール。** エンチャントは直接購入ではなくロール制なので、ばらつきは現実に存在します。ロールに使う前に、自分のビルドに何が足りないかを決めておきましょう。
- **ターゲット選択。** アップグレードの進んだプレイヤーを狩ることにはボーナスXPが明示的に用意されているので、最も稼げる戦いは最も危険な戦いでもあります。
- **戦闘の作法。** デュエルへの漁夫の利、遮蔽物の利用、低HPでの離脱は、どの単一アップグレードよりも「1ライフあたりのダメージ」を押し上げます。

有用なセルフチェック：キルよりデスが多いなら、問題はほぼ確実にダメージではありません。ポジショニングです。負けた戦いをギアのせいにするプレイヤーは、たいてい30秒前に三人に見られながら開けた通路へ踏み込んだ時点で負けていたのです。

## 上昇に最適なクラス

ゲームには8つのクラスがあります：ウォリアー、アーチャー、トリックスター、トラッパー、スカーミッシャー、ファイアスターター、ボマー、スコーチャー。説明文には能力の全容は書かれていないため、以下の役割はクラス名から連想されるものと、アリーナ系PvPゲームに関するコミュニティ報告から一般的に推測されるものを反映しています。出発点として扱い、絶対の真実とは考えないでください。

| クラス | 想定される役割 | 向いているプレイヤー |
|---|---|---|
| ウォリアー | 近接の前衛 | 真っ向から勝負を仕掛けるのが好きな人 |
| アーチャー | 遠距離からのプレッシャー | 装備が整わないうちに距離を保ちたい人 |
| トリックスター | 回避と攪乱 | 不利な戦いからの離脱と立て直し |
| トラッパー | エリア制圧 | チョークポイントの封鎖と逃走の阻止 |
| スカーミッシャー | ヒットアンドアウェイ | デュエル後の弱った相手を仕留める |
| ファイアスターター | エリア封鎖 | 相手を強力な遮蔽物から追い出す |
| ボマー | 範囲への瞬間火力 | 混戦と後始末 |
| スコーチャー | 持続的なプレッシャー | 消耗戦で勝つ長期の殴り合い |

初めて本気でランを狙うなら、1つのクラスを選び、最低十数回のデスまでそれを使い続けてください。クラスを次々乗り換えると、死んだ原因がギアなのか相性なのか自分の判断なのか分からなくなります。**1 Upgrade Per Kill** では死ぬたびにすべてリセットされるモードなので、はっきりしたフィードバックはバリエーションよりも価値があります。

## ゴールド、エンチャント、パーク、Gear Saver

ゴールド、エンチャントロール、パーク、クレート、ケープはすべて同じ注意力を奪い合っており、新規プレイヤーはあれこれ手を広げがちです。賢いのは、出費の順番を決めて、購入のたびに次のランが楽になるようにすることです。

### ゴールドの使い道

| 出費先 | 得られるもの | 上昇を目指すプレイヤーの優先度 |
|---|---|---|
| パーク（ゴールド） | ランをまたいで持続する購入型アップグレード | 高 — 挑戦のたびに積み上がる |
| エンチャント（ロール） | ランダムなギア強化 | 中〜高 — ビルドが固まってから回す |
| クレート | ランダム報酬 | 中 — 楽しいがばらつきが大きい |
| ケープ | コレクション用コスメ | 落ち着くまでは低 |

ゲームの説明文では、無料ギフト用の **WELCOME** コードとグループ報酬も告知されています。こうしたプロモコードは時期によって入れ替わるので、見かけたものは後回しにせず早めに引き換えましょう。無料のスタート価値は、新規アカウントにこそ必要なものです。

### Gear Saver を使うタイミング

Gear Saver の目的はただ一つ、高いアップグレードで死んだときにアーマーを保持できるようにすることです。限られた資源なので、持っているかどうかよりも「どこで使うか」が重要です。

| 状況 | 使う？ | 理由 |
|---|---|---|
| シャドウ、プリズム、MAXED で死んだ | はい | 最も価値の高いはしご位置を守っている |
| レザーやカッパーで死んだ | いいえ | やり直してもほとんど失うものがない |
| 慣れないクラスを試している | いいえ | 安いデスは学習のうち |
| リーダーボードの連勝を伸ばしている | はい | Best Streak の進捗は立て直しが難しい |
| 短時間プレイの終わり | 場合による | すぐ戻るなら温存する |

コミュニティ報告によると、最も多い Gear Saver の失敗は、アイアンやフルダイヤモンドで慌てて使ってしまい、プリズムで使う分が残っていないというパターンです。これは最高のランのための保険であって、すべてのランの安全網ではありません。

### 高いアップグレードを守る習慣

- **遮蔽物の近くで戦う。** 逃げ道が一つ増えるほうが、わずかなダメージ増より価値があります。
- **開けた場所へ追いかけない。** ルビー以上でのデスの多くは、待ち伏せではなく追跡から始まります。
- **優位があるときだけ高アップグレードのプレイヤーを狩る。** ボーナスXPは確かに存在しますが、相手のギアも確かに存在します。
- **デスのたびに頭をリセットする。** レザーでの新しいランは巻き返しの試みではなく、まっさらなスタートです。
- **戦闘の合間にリーダーボードを確認する。** 誰が強いかを知っていれば、誰を避け、誰に漁夫の利を狙うべきかが分かります。

## FAQ

**1 Upgrade Per Kill とは何ですか？**
すべての撃破でギアが1段階アップグレードされ、死ぬたびにゼロへ戻される Roblox のフリーフォーオール・アリーナです。レザー、カッパー、アイアン、フルダイヤモンド、ルビー、シャドウ、プリズムを経て MAXED を目指して上る一方、ロビーの他の全員があなたのランを終わらせようとしてきます。

**1 Upgrade Per Kill 最大ダメージを狙うなら、すべての戦いを受けるべきですか？**
いいえ。このモードでのダメージは、高いティアを維持できるほど長く生き延びた結果にすぎません。すべての戦いを受けると序盤は上昇が速まり、終盤はランを壊します。最も長い連勝を残すプレイヤーは、シャドウを超えたあたりで静かになるのが普通です。

**長期の連勝に最も簡単なクラスはどれですか？**
万能に最適なクラスはありませんが、マップをまだ覚えている途中のプレイヤーには、遠距離系や制圧系の選択肢のほうが寛容な傾向があります。1つのクラスを選んで十数ラン使い続け、キル数ではなく生存率で評価してください。

**Gear Saver は連勝を丸ごと保持してくれますか？**
高いアップグレードで死んだ後にアーマーを保持してくれるもので、そこがランの高くつく部分です。完全な巻き戻しボタンではなく、ギアと Best Streak の進捗を守る保険と考え、すべてを失うと本当に痛いティアのために取っておきましょう。
