1キル＝1アップグレード——それが**1 Upgrade Per Kill**のすべてです。これはRobloxのフリーフォーオール・アリーナで、装備ティアがそのまま連続キル数のライブスコアボードになります。撃破するたびに武器と防具が階段を1段上がり、死ぬたびにLeatherへ戻されるため、このゲームは普通のPvP反射神経をリスク管理のパズルへと変えます。なぜあるプレイヤーは数分でMAXEDまで雪だるま式に上がり、他の3人はCopperで足踏みするのか——**1 Upgrade Per Kill**のダメージアップグレード、ティア進行、クラス、Gear Saverを分解すれば、その差がどこから生まれるかが正確にわかります。

## 1 Upgrade Per Killのループは実際どう動くのか

基本ルールは残酷なほどシンプルです。誰かを倒せば1ティア上がり、死ねばゼロに戻る。部分点も緩やかな着地もありません。つまり装備ティアは単なるステータス強化ではなく、ロビーの全員が一目で読み取れる公開の脅威レベルなのです。

ゲーム自体の説明によると、上昇は固定された素材の階段を進みます。各段階は選択肢のメニューを与えるのではなく装備全体の品質を引き上げるので、重要な判断は「戦い続けるか、離脱して今持っているものを守るか」だけになります。

| ティア | 意味 | リスクレベル |
|---|---|---|
| Leather | 初期装備、失うものはない | 最小 |
| Copper | 最初の本格的な一歩 | 低 |
| Iron | 階段の中段、防具が効き始める | 中 |
| Full Diamond | ランキングで追跡される基準ティア | 中 |
| Ruby | 平均以上の脅威、目をつけられる | 高 |
| Shadow | 階段後半の戦力、格好の狩り対象 | 高 |
| Prism | 頂上まであと1キル、ゼロまであと1死 | 非常に高 |
| MAXED | 階段の頂点。ロビー全員があなたを狙う | 極限 |

PrismからMAXEDへの跳躍は1キルなので、ほとんどの連続キルはこの最後の2ティアで潰えます。それを理解しているプレイヤーは、階段の上部と下部でまったく違う立ち回りをする傾向があります。

## ダメージアップグレード：なぜキルのたびに雪だるま式に強くなるのか

プレイヤーが最も検索するフレーズが**1 Upgrade Per Kill**のダメージアップグレードです。理由は単純で、ダメージこそ次のキルがどれだけ早く来るかを決めるステータスだからです。コミュニティの報告によれば、各ティアは攻撃力と防具の保護の両方を高め、それが複利的なループを生みます——ダメージが上がればキルが早くなり、キルが早くなれば第三者に漁られる隙が減るのです。

| アップグレード要素 | 変化 | 実戦での効果 |
|---|---|---|
| 1発あたりの武器ダメージ | ティアごとにスケールアップ | 決闘がより少ない攻撃回数で終わる |
| 防具の保護 | ティアごとにスケールアップ | 流れ弾やトレードにより耐えられる |
| 実効キル速度 | ダメージ上昇とともに改善 | 毎分のキル数が増え、上昇が速くなる |
| ターゲット価値 | ティアとともに上昇 | 高ティアはボーナスXP目当てに狩られる |
| リセットコスト | ティアとともに上昇 | 高く上るほど失うものが大きい |

最後の行が罠です。Leatherのプレイヤーは賭け金がゼロなので、無謀な攻撃性にコストはかかりません。同じ攻撃性を持つShadowのプレイヤーは、1回の悪いトレードに数分間のクリーンな立ち回りを賭けているのです。低ティアの無謀さと高ティアの慎重さの非対称性を理解することが、このゲーム最大のスキル差です。

もう1つ注目すべき点があります。アリーナにはクリティカル、ノックバック、機能的な防具値があるため、生のダメージだけが変数ではありません。位置取りが優れたプレイヤーはより高いティアに勝てます。だからこそ階段はエイムと同じくらい忍耐に報いるのです。

## 8つのクラスとそれぞれの得意分野

ロスターには8つのプレイアブルクラスがあり、それぞれ異なる戦闘スタイルを推します。以下の役割は公式のステータス表ではなく、クラス名とコミュニティの経験に基づくものです。自分で試す際の出発点として扱ってください。

| クラス | 想定される役割 | 最も活きる場面 |
|---|---|---|
| Warrior | 前線の近接ブルーザー | 真っ向からの決闘と場所の確保 |
| Archer | 遠距離からのポークダメージ | 踏み込む前に相手を削る |
| Trickster | 機動力と撹乱 | ガンクからの離脱と戦闘のリセット |
| Trapper | エリア制圧 | チョークポイントと逃走経路の封鎖 |
| Skirmisher | ヒットアンドラン | 進行中の決闘への横槍 |
| Firestarter | 継続ダメージ／ゾーニング | 安全地帯から相手を追い出す |
| Bomber | 範囲バーストダメージ | 混戦や集団の小競り合い |
| Scorcher | 積極的なプレッシャー | 負傷した低ティアの追撃 |

初めての上昇では、機動力のあるクラスや遠距離クラスのほうが寛容です。負けている戦闘から離脱できるからです。近接ブルーザーはコミットメントに報いますが、コミットメントこそがPrismで死ぬ原因でもあります。

## ゴールド、エンチャント、クレート、Gear Saver

**1 Upgrade Per Kill**の進行は階段だけではありません。ゲームはその上にいくつかのサイドシステムを重ねており、どれが連続キルを守るかを知ることは見た目以上に重要です。

| システム | 関わり方 | 重要な理由 |
|---|---|---|
| Gold | プレイで獲得し、Perkに消費 | 階段の外でのほぼ永続的な優位 |
| Enchants | 装備モディファイアを厳選 | ばらつきとビルドの個性を追加 |
| Crates | 報酬のために開封 | コスメティックとおまけ |
| Capes | 収集 | コスメティックな進行 |
| Gear Saver | 高アップグレード時に死亡すると消費 | リセットせず防具を維持 |
| Codes | ゲーム内で引き換え可能 | ゲーム説明に無料ギフトのWELCOMEコードの記載あり |

際立っているのはGear Saverです。RubyやShadowで死ぬと通常はすべて消えますが、Gear Saverがあれば防具を維持でき、壊滅的な損失1回を対処可能な後退へと変えます。上の2ティアのために取っておきましょう——Ironで使うのは無駄です。

クレート、ケープ、エンチャントは彩りを加えますが、どれも基本の代わりにはなりません。戦いに勝ち、ティアを取り、欲張った追撃を避けることです。

## MAXEDへより早く到達するための実践的なコツ

コミュニティの報告は一貫して、速く上るプレイヤーとDiamond付近で頭打ちになるプレイヤーを分ける同じいくつかの習慣を指摘しています。

| 状況 | 推奨プレイ | 避けること |
|---|---|---|
| LeatherからIron | 常に戦い、リスクを取る | 隠れる——足踏みしても何も得られない |
| Full Diamond | 戦う相手を選び始める | マップ全体をまたいでキルを追う |
| RubyからShadow | 端で戦い、負傷した相手を仕留める | 万全な相手との開けた場所での決闘 |
| Prism | 早めに離脱し、頻繁にリセット | 欲張った横槍 |
| MAXED | 生き残り、守り、相手に来させる | あと1キルのために無理に踏み込む |

身につける価値のある具体的な習慣をいくつか：

- **負傷した相手を先に仕留める。** 低HPのターゲットは、あなたが買える最も安いティアです。
- **群衆の中へ追いかけない。** ノックバックと第三者からの横槍は、視野の狭さを何よりも罰します。
- **誰が自分を狙っているか把握する。** ゲームは高アップグレードのプレイヤーを狩ることにボーナスXPを与えるので、Diamondを超えたらあなたは賞金首です。
- **Gear Saverを蓄えておく。** PrismとShadow専用の保険として扱いましょう。
- **キルのたびにリセットする。** キル直後はたいていHPが低いままです。次の戦闘は相手の都合ではなく、自分の条件で始めるべきです。

## ランキング、連続キル、高ティア狩り

ゲームはBest Streak、Top Kills、Fastest Diamondのランキングを追跡しており、開発者が何をスキルと見なしているかがよくわかります。Best Streakは生存に報い、Top Killsは量に報い、Fastest Diamondは効率的な序盤の攻撃性に報います。3つすべてを同時に最適化することはできないので、自分のクラスとプレイスタイルに合うボードを選びましょう。

新規プレイヤーにとって最も興味深いのは「Fastest Diamond」カテゴリです。ほぼ最初の5分間がすべてだからです。Full Diamondに早く到達するには、誰も防具を持たずトレードが短い序盤に、勝てる戦いをすべてこなすことです。ロビーが成熟しShadowのプレイヤーが徘徊し始めると、その窓は閉じます。

## FAQ

**1 Upgrade Per Killで死ぬとダメージアップグレードはリセットされますか？**
はい。死ぬとLeatherに戻され、ダメージのスケーリングと防具の両方が失われます。損失を和らげる唯一の方法はGear Saverで、高いアップグレードを保持したまま死んだ場合に防具を維持できます。

**1 Upgrade Per Killで最速の上昇方法は？**
失うものがない低ティアでは積極的に戦い、Diamondを超えたら選択的で戦闘の端を突く立ち回りに切り替えましょう。速い上昇のほとんどは、公平な決闘に勝つことではなく、負傷したプレイヤーを仕留めることから生まれます。

**初心者はどのクラスを選ぶべきですか？**
ArcherやTricksterのような遠距離・機動力系が最も寛容です。負けている戦闘から離脱できるからです。近接クラスも同じくらい高く上れますが、より優れた位置取りの規律が求められます。

**WELCOMEコードでは何がもらえますか？**
ゲーム自体の説明には、無料ギフト用のWELCOMEコードと、関連コミュニティグループへの参加で追加報酬がもらえることが記載されています。コードは早めに引き換えましょう——追加リソースは最初の数回の上昇で最も役立ちます。
