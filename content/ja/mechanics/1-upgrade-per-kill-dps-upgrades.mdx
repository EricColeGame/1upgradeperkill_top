## 1 Upgrade Per KillのDPSアップグレードが特別な理由

1キルにつき1アップグレード——それが1 Upgrade Per Killの約束のすべてであり、ゲームがこれほど早く緊迫する理由でもあります。1 Upgrade Per KillのDPSアップグレードを理解するには、ひとつの不快なルールを受け入れる必要があります。それは、あなたの火力とアーマーがHUD上のたったひとつのカウンターに縛られているということです。勝利するたびにそのカウンターは前進し、死ぬたびにゼロへと消し飛びます。つまり、そこそこのランと圧倒的なランの差は、たいていエイムの精度ではなく、ほんのいくつかの賢明な判断で決まるのです。

ほとんどのRobloxのPvP体験では、ショップやセーブデータ、恒久的なインベントリに進行状況を貯められます。このゲームは違います。あなたのDPSは一時的なものであり、常にたった一度の敗戦で消え去る瀬戸際にあります。

このひとつの設計判断が、あなたの立ち回りを変えます。あなたは快適なペースでゴールを目指して周回しているのではありません——雪だるまを守っているのです。長く保持するほど強く叩け、強く叩くほど次のアップグレードが早く訪れます。

| 基本ルール | 実際の意味 |
| --- | --- |
| キル = +1アップグレード | 敵を倒せば、装備が階段を1段上がる |
| 死亡 = ゼロにリセット | 1段だけでなく、積み上げたすべてを失う |
| アップグレードは装備間で共有 | アーマーと（おそらく）武器は同じカウンターを消費する |
| 進行はライフ単位 | パークとGear Saver以外はライフをまたいで持ち越せない |
| 雪だるま効果 | アップグレードが高いほど次のキルが楽になり、リードが複利で増える |

雪だるまこそがゲームのすべてです。PrismにいるプレイヤーはLeatherのプレイヤーより単に硬いだけでなく、ロビーをより速く刈り取っています。つまり、他の全員がまだ立て直している間にMAXEDへ到達するのです。

## アーマーの全階段：LeatherからMAXEDまで

装備の階段は8つの名前付きアーマー層を通ります。Leatherが確認済みのスタート地点で、MAXEDが頂点です。リストの中盤はゲーム自体の説明文に由来しますが、いくつかの段はまだコミュニティによって独立検証されていません。

| # | 層 | 備考 |
| --- | --- | --- |
| 1 | Leather | 開始層。最初のアップグレードでLeatherのパーツが追加される |
| 2 | Copper | ゲーム説明に記載。独立検証はまだ |
| 3 | Iron | ゲーム説明に記載。独立検証はまだ |
| 4 | Full Diamond | 確認済み — 専用の「Fastest Diamond」リーダーボードが存在する |
| 5 | Ruby | ゲーム説明に記載。独立検証はまだ |
| 6 | Shadow | ゲーム説明に記載。独立検証はまだ |
| 7 | Prism | ゲーム説明に記載。独立検証はまだ |
| 8 | MAXED | 最終ステップ。アップグレード34で到達 |

ここで注目すべき点が2つあります。第一に、「Full Diamond」は単一パーツではなく完成した一式として名付けられており、ゲームが完成した装備構成をマイルストーンとして扱っていることが分かります。専用のスピードラン風リーダーボードが用意されるほどに。第二に、DiamondからRuby、Shadow、Prism、MAXEDへと続く跳躍は、終盤こそ1 Upgrade Per KillのDPSアップグレードがプレイヤーを本当に分ける場所であることを示唆しています。各層がおそらく火力と生存性の両方を同時に加えるからです。

「Fastest Diamond」ボードを狙うなら、実用的な結論は「終盤のキルより序盤のキルが重要」ということです。最小のキル数でFull Diamondに到達するプレイヤーとは、コイントスのような勝負に一度もライフを無駄にしなかったプレイヤーです。

## 34ステップカウンターの謎を解く

HUDには**UPGRADE 2/34**と表示され、合計34ステップであることが確認できます。興味深いのは、その34ステップが8つのアーマー層にどう対応するかです。

広く共有されているコミュニティの説では、こう計算します。8層 × 4つのアーマースロット（ヘルメット、チェストプレート、レギンス、ブーツ）＝32ステップ。残る2ステップは説明がつかず、おそらく武器のアップグレードでしょう。これはデイリークエスト「Reach Full Leather」とも符合します。つまり、いきなり一式に飛ぶのではなく、各層をパーツ単位で組み上げていくということです。

| 主張 | 状態 | 出典 |
| --- | --- | --- |
| アップグレードは合計34ステップ | 確認済み | ゲーム内HUDカウンター |
| Leatherが最初の層 | 確認済み | プレイ映像 |
| Full Diamondが層として存在 | 確認済み | 専用リーダーボード |
| 各層はパーツ単位で構築される | 強く示唆される | 「Reach Full Leather」デイリークエスト |
| アーマー32ステップ + 武器2ステップ = 34 | コミュニティの説 | プレイヤー体験によるもので、公式確認はなし |
| 1ステップあたりの正確なDPS上昇量 | 未確認 | 公開された数値はまだなし |

32 + 2の内訳は実用上のモデルとして扱い、絶対の真実とは考えないでください。カウンターをきれいに説明できますが、開発者が完全なステップリストを公開するまでは、コメント欄で見かける「1アップグレードあたりの具体的な数値」はすべて推測です。

## 死亡、Gear Saver、そしてDPSの守り方

死ぬことはゲーム内で最も高くつくミスです。1段を失うのではなく、階段そのものを失うからです。例外はGear Saverで、これは死亡をまたいで進行状況を保持します。

| 状況 | 結果 | 緩和策 |
| --- | --- | --- |
| 保護なしで倒される | 完全にゼロへリセット | なし — 積み上げは消える |
| Gear Saver所持中に倒される | 進行状況を保持 | Gear Saverはアップグレードが高いライフに取っておく |
| Head Startありで新規スポーン | Leatherのパーツをいくつか持って開始 | パークスロットを消費しないため、ほぼ無償の価値 |
| Head Startなしで新規スポーン | ゼロから開始 | 最初の2分が遅くなることを受け入れる |

Head Startパークは、通常よりもっと評価されるべきです。パークスロットを消費しないため、毎ライフ実質無料のアーマーになります。そして1 Upgrade Per KillのDPSアップグレードが絶えずリセットされるゲームでは、無料の序盤ステップは最も繰り返し得られるアドバンテージです。

Gear Saverを使うかどうかは判断の分かれるところです。アップグレード5で使うのは無駄遣い、MAXEDまで2ステップというアップグレード28での使用は明白です。プレイヤー体験はおおむねひとつのルールで一致しています。Gear Saverの価値はすでにどれだけ高いかで決まるので、序盤には決して使わないこと。

## より速く駆け上がる方法：実践的なコツ

アップグレードの速さは、決闘に勝つことだけではありません。すでに自分に有利に傾いている戦いを選ぶことです。

| 戦術 | 効果 | 注意点 |
| --- | --- | --- |
| 低体力のプレイヤーを狩る | 確実に素早いキルとステップを得る | 回復される前に見つける必要がある |
| Seerクラスを使う | 敵のハートを可視化し、標的を選べる | 他に使いたいクラススロットを消費する |
| 高アップグレードのプレイヤーを狙う | ボーナスXPと懸賞金 | リスク最大、リターン最大 |
| Golden Appleを食べる | 劣勢の戦いを有利にリセット | 量よりタイミングが重要 |
| Server Boostを買う | GoldとXPの獲得量が増える | アップグレード速度は**上がらない** |
| Head Startパークを使う | スポーンごとに無料のLeatherパーツ | Leatherを超えると役に立たない |

間違えられやすいのがServer Boostの行です。ブーストは経済面の進行には最適ですが、アップグレードカウンター自体には何の効果もありません。目的が1 Upgrade Per KillのDPSアップグレードを上げることなら、通貨は生き残るために使うべきです。

ポジショニングも同じくらい重要です。すでに半分終わった戦いに横から介入する方が、新しい決闘を始めるよりほぼ常に良い結果になります。弱った相手を引き継げ、ほとんど体力を消費せずにキルを得られるからです。節約したハートは、すべて次の戦いに使えるハートです。

## DPSを助けるクラス、パーク、サポートシステム

装備の選択が、キルをアップグレードへどれだけ確実に変換できるかを決めます。

- **Seer** — 標的選択が土台のゲームでは、情報が最強のステータスです。どの敵がほぼ死にかけているか分かれば、当て推量が確実な1ステップに変わります。
- **Head Start** — パークスロットを消費せず、スポーン時に無料のLeatherパーツ。頻繁に死ぬプレイヤー、つまりほとんどのプレイヤーにとって最高のコスパ枠です。
- **Gear Saver** — 戦略ではなく保険。ランの終盤まで取っておきましょう。
- **Golden Apple** — 戦闘中のリセットボタン。負けトレードを勝ちトレードに変えます。
- **Server Boost** — 経済専用。アンロックには有用ですが、階段そのものには無関係です。

パターンは単純です。キルを早く*終わらせる*のに役立つものは、長く生き残るのに役立つものより価値があります。キルを終わらせることがカウンターを進めるからです。防御はすでに得たDPSを守るだけです。

## よくある質問

**1 Upgrade Per KillのDPSアップグレードは全部でいくつありますか？**
HUDカウンターは2/34と表示されるので、34ステップです。MAXEDが最後で、Prismの後に到達します。

**死ぬと1 Upgrade Per KillのDPSアップグレードはすべて失われますか？**
はい——Gear Saverを持っていない限り、死亡でゼロにリセットされます。このリセットは直近の1段だけでなく、積み上げ全体に適用されます。

**1 Upgrade Per KillのDPSアップグレードを最速で上げる方法は？**
素早く終わらせられる戦いを選びましょう。すでにハートが少ないプレイヤーを狩り、Seerクラスで彼らを見つけ、弱った標的が近くにいるときに新しい決闘を始めるのは避けてください。

**Server Boostを使うとアップグレードは速くなりますか？**
いいえ。ブーストはGoldとXPを増やすもので、アップグレードカウンターは増やしません。階段を上がれるのはキルだけなので、報酬を増やすものよりキルレートを上げるものの方が重要です。
