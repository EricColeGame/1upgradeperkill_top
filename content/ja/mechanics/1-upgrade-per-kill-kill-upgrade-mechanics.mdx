## 1 Upgrade Per Killのキルアップグレード仕組みの働き

1キル、1アップグレード。1デス、ゼロに戻る。

この一文が**1 Upgrade Per Kill**の設計そのものであり、**1 Upgrade Per Kill**のキルアップグレード仕組みがエイムと同じくらい忍耐を報いる理由を説明しています。敵を倒すたびに、アーマーと武器が固定のはしごを1段ずつ上がります。死ぬたびに、最下段まで引き戻されます。部分的な報酬も、蓄積された進行も存在しないため、キルを重ねるほどプレッシャーは高まります。

アリーナはフリーフォーオールのPvPで、クリティカルヒット、ノックバック、そして実際にダメージを軽減するアーマーが特徴です。チームがないため、不利なトレードをカバーしてくれる味方もおらず、カムバックを計画できる長いリスポーンタイマーもありません。代わりに得られるのは雪だるま式の優位です。ティア4にいるプレイヤーは、ティア1にいるプレイヤーとの真っ向勝負でほぼ毎回勝ちます。

だからこそ、アップグレードの高いプレイヤーを狩るとボーナスXPがもらえるのです。ゲームは意図的に最強のプレイヤーを動く賞金首に仕立て上げるので、ロビーが膠着状態に陥ることはありません。もしあなたが登っているなら、訪問者を期待しましょう — しかもすぐに。

| アリーナでの行動 | 装備に何が起こるか | 戦略的に何を意味するか |
|---|---|---|
| プレイヤーを倒す | +1アップグレード段階 | すぐに優位を押し広げる |
| 倒される | レザーにリセット | 損失は完全、だからリードを守る |
| アップグレードの高い標的を倒す | ボーナスXPを獲得 | ロビーの頂点は標的になる |
| 長い連続キルを維持する | ティアが高いほど脅威も高い | 力と危険は共に上がる |

## レザーからMAXEDまでのアーマーのはしご

進行ルートは固定され、見えていて、1セッションで覚えられるほど短いです：レザー → コッパー → アイアン → フルダイヤモンド → ルビー → シャドウ → プリズム → MAXED。8段のはしごで、それぞれが生存性の実際のジャンプです。アイアンからフルダイヤモンドへのジャンプは、多くのプレイヤーが危険を感じ始める瞬間です。なぜなら、それが装備が「作業中」ではなく完全なセットとして初めて読める瞬間だからです。

コミュニティの報告では、上位3ティア — ルビー、シャドウ、プリズム — を、戦闘が決闘に変わる地点と表現しています。その高さにいるプレイヤーは単にタフなだけでなく、他の全員にとってボーナスXPの価値もあるため、ロビーは静かに彼らを倒すことを中心に組織化されます。

| ティア | はしご上の位置 | どんな感覚か | 脅威レベル |
|---|---|---|---|
| レザー | 初期装備 | 脆く、失っても許される | 低 |
| コッパー | 最初のアップグレード | クリティカルに対するわずかな緩衝 | 低 |
| アイアン | 序盤の勢い | ミスを生き延びられる | 中 |
| フルダイヤモンド | 中盤のマイルストーン | 最初の「本物の」パワースパイク | 中 |
| ルビー | はしごの上層 | 戦闘が長く、緊迫する | 高 |
| シャドウ | エリート領域 | あなたは今や賞金首 | 非常に高い |
| プリズム | 頂上付近 | 1つの悪いトレードでランが終わる | 極めて高い |
| MAXED | 天井 | 最大のプレッシャー、最大の見返り | 極めて高い |

この表からの実践的な結論はシンプルです：登るにつれて、リスク許容度を縮めるべきです。レザーでは、五分五分の戦闘はほとんど何も失いません。プリズムでは、同じ五分五分の戦闘がラン全体を失わせます。

## クラス：登攀に適した道具を選ぶ

**1 Upgrade Per Kill**には8つのクラスがあります：ウォリアー、アーチャー、トリックスター、トラッパー、スカーミッシャー、ファイアスターター、ボマー、スコーチャー。それぞれがキルを生み出す方法を変え、キルはアップグレードにとって唯一重要な通貨であるため、クラス選択は本当に*次の段階をどう稼ぐつもりか*という問題です。

以下の説明はプレイヤーの経験と各クラス名が示すものに基づいています — 開発者はバランスを回転させるので、これを福音ではなく出発点として扱ってください。登攀を決意する前に、低リスクのロビーで2、3試してください。

| クラス | 想定される役割 | 向いている人 | 注意点 |
|---|---|---|---|
| ウォリアー | 純粋な近接ブルーザー | 公平な戦闘が好きなプレイヤー | 遠距離ビルドにカイトされる |
| アーチャー | 遠距離からの圧力 | 弱い標的を狙い撃つ | 近距離では脆い |
| トリックスター | 機動性とミスディレクション | 不利なトレードからの脱出 | 素のダメージが低い |
| トラッパー | エリア封鎖 | チョークポイントを封じる | 開けた地形では弱い |
| スカーミッシャー | ヒットアンドラン | 単発キルを素早く稼ぐ | 絶え間ない位置調整が必要 |
| ファイアスターター | 継続ダメージ | 交戦前に標的を弱らせる | キルを決めるのが遅い |
| ボマー | 瞬間範囲ダメージ | 混戦 | 外すと痛い |
| スコーチャー | 攻撃的な圧力 | 序盤のリードを雪だるま式に | 高ティアではリスクが高い |

純粋に連続キルを守ることが目標なら、機動性と遠距離クラスの方が寛容な傾向があります。トップキルリーダーボードが目標なら、バーストダメージクラスの方が速く量を生み出します。

## ゴールド、エンチャント、クレート、ギアセーバー

キルは**1 Upgrade Per Kill**の唯一のシステムではありません。ゲームははしごの上に小さな経済を重ねており、何に使うかを知ることが良いランの持続時間を変えます。ゴールドはパークを買います。エンチャントは装備に追加効果を付けるためにロールされます。クレートはコスメとケープをドロップします。そしてギアセーバーはまさに1つの目的のために存在します：高ティアのランを1つのミスから守ることです。

| システム | 何をするか | 新規プレイヤーにとっての優先度 |
|---|---|---|
| ゴールドとパーク | 稼いだゴールドで買うほぼ永続的なブースト | 高 — 早めに使う |
| エンチャント | 装備にロールされる修正効果 | 中 — 登ってからロール |
| ギアセーバー | 高アップグレード時に死んでもアーマーを維持 | ダイヤモンド以上では非常に高 |
| クレート | コスメとケープ | 低 — 楽しいが戦力ではない |
| ケープ | 見た目の飾り | コスメのみ |

ギアセーバーはゲーム内で最も誤解されているアイテムです。新規プレイヤーは理由もなく溜め込み、経験者はフルダイヤモンドに到達した瞬間に燃やします。なぜなら、そのティアでは1回のリセットが最も多くの時間を消し去るからです。これをトロフィーではなく、リードに対する保険として扱ってください。

また、無料ギフトをもらえるプロモコード「WELCOME」があり、関連グループに参加すると別のギフトがもらえると報告されています。どちらも最初の本格的な登攀の前に取得する価値があります — 無料リソースは序盤にパークに使うと複利で効きます。

## 連続キルのコツとリーダーボードの目標

ほとんどのプレイヤーは、同じいくつかのミスでアップグレードを失います。そのうち3つを修正することは、どんなバランス変更よりも登攀に役立ちます。

| よくあるミス | より良い習慣 |
|---|---|
| 開けた地形でキルを追いかける | 視線を切り、戦闘をリセットする |
| 脱出計画なしでフルHPで戦う | 交戦前に常に出口を把握する |
| スコアボードを無視する | 誰がプリズムにいるかを追跡し、そのレーンを避ける |
| レザーでギアセーバーを燃やす | ダイヤモンド以上まで取っておく |
| 高ティアで疲れてプレイする | ランを貯めて、余裕を持ってログオフする |

リーダーボードは、ゲームが実際に何を評価しているかを教えてくれます：ベスト連続キル、トップキル、最速ダイヤモンド。それぞれ異なるスタイルを報い、3つを同時に追うと通常はどれも極められません。

| リーダーボード | 何を報いるか | どう取り組むか |
|---|---|---|
| ベスト連続キル | 生存と一貫性 | 安全にプレイし、勝てる戦闘だけを受ける |
| トップキル | 量と攻撃性 | 高ダメージクラス、絶え間ない圧力 |
| 最速ダイヤモンド | 序盤の効率 | 最初の4キルを最適化する |

最速ダイヤモンドは3つの中で最も過小評価されています。これは、終盤の装備アドバンテージに頼るのではなく、ランの最初の1分 — 実際にほとんどのアップグレードが勝ち取られるか失われる部分 — を学ぶことを強制します。

## FAQ

**1 Upgrade Per Killのキルアップグレード仕組みを一文で表すと？**
敵を倒すたびに装備がレザーからMAXEDへのはしごを1ティア上がり、死ぬたびにレザーにリセットされるので、進行は完全に生き残ることに依存します。

**死んだらすべてを失いますか？**
アップグレードティアはゼロにリセットされます。ギアセーバーは、高いアップグレードを持っている間に死んだ場合にアーマーを保持できるので、経験者がフルダイヤモンド以上まで取っておく理由です。

**はしごを登るのに最適なクラスは？**
普遍的な答えはありません — ベスト連続キル、トップキル、最速ダイヤモンドのどれを追うかによります。機動性クラスは連続キルを守り、バーストダメージクラスはキルの量を生み出します。コミュニティの報告では、決める前にいくつか試すことを勧めています。

**1 Upgrade Per Killはpay-to-winですか？**
進行のはしご自体はキルで稼ぎます。ゴールド、パーク、ギアセーバーは登攀を補助しますが、購入がコア要件を置き換えることはありません：死なずに戦闘に勝たなければならないのです。
