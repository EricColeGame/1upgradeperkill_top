## アップグレードラダー：各ティアが実際に変えるもの

このゲームの進行は驚くほど分かりやすくできています。公式の[+1 Upgrade Per KillのRobloxページ](https://www.roblox.com/games/113273588963037/1-Upgrade-Per-Kill)によれば、装備はLeather → Copper → Iron → Full Diamond → Ruby → Shadow → Prism → MAXEDという固定の順序で上がっていきます。ラダーが固定されているからこそ、ビルドの選択とは「ラダーのどこで危険な存在になりたいか」を決めることになります。

| ティア | 意味するもの | この段階でのビルド優先度 |
|---|---|---|
| Leather / Copper | 開始数分、防御は最小限 | 生き残る。確実に仕留められる戦いだけを選ぶ |
| Iron | 初めての実質的なアーマー優位 | 中位ティアのプレイヤーに挑み、ボーナスXPを狙う |
| Full Diamond | 定番の「高速Diamond」チェックポイント | 固める。欲張った追撃を避ける |
| Ruby | 装備差が急速に開く | マップではなくクラスの勝ち筋をプレイする |
| Shadow | 高アップグレード領域 | 連勝を守る。Gear Saverを保持する価値が出る |
| Prism | 天井に近いパワー | 他の高アップグレードプレイヤーを狩り、XPを大きく動かす |
| MAXED | 天井到達 | パワーをリーダーボードの成績に変換する |

ゲーム説明にある2つのディテールが、リスクの考え方を変えます。1つ目は、高アップグレードのプレイヤーを狩るとボーナスXPが得られるということ。つまり目に見えて強いことは、背中に的を描くことと同じです。2つ目は、Gear Saverが「高アップグレードで死んだときにアーマーを維持したいプレイヤー」のために存在するということ——先を見据えて動けば、ラダーは純粋なゼロサムではありません。

**重要なポイント：** ラダーは最初の3ティアでは忍耐を、最後の3ティアでは攻撃性を報います。ほとんどの連勝は、プレイヤーがそれを逆にしたせいで死にます。

## 1 Upgrade Per Killで最強ビルドに適したクラスの選び方

全員にとって数学的に正しい単一のクラスは存在しません——**1 Upgrade Per Kill** における最強ビルドとは、そのクラスの離脱手段とフィニッシュ手段が、あなたの実際の戦い方に噛み合っているビルドです。ロスターにはWarrior、Archer、Trickster、Trapper、Skirmisher、Firestarter、Bomber、Scorcherが揃っており、それぞれがクリティカル・ノックバック・実アーマーを備えた自由参加型アリーナで異なる役割を担います。

| クラス | 自然な役割 | 輝く場面 | 主なリスク |
|---|---|---|---|
| Warrior | 前線のブルーザー | アーマー優位を活かした真っ向勝負 | ファイト中に第三者に漁夫の利を取られる |
| Archer | 遠距離からの圧力 | 仕掛ける前にターゲットを削る | 距離を詰められると弱い |
| Trickster | 機動力とミスディレクション | 不利な戦いからの離脱、連勝のリセット | 純粋なフィニッシュ力が低い |
| Trapper | エリアの封鎖 | チョークポイントと退路の制御 | 高速なロビーでは設置時間が取れない |
| Skirmisher | ヒットアンドラン型のデュエル | 短いトレード、素早い離脱 | もう一撃を狙って深追いしがち |

| Scorcher | 攻撃的なエリア制圧 | リードした状態からのスノーボール | 劣勢時に餌になる |

コミュニティ全体のプレイヤー体験は一貫して同じパターンを示しています。機動力と離脱手段は長期連勝で性能を発揮し、純粋なダメージクラスは短期的な爆発力で勝る、というものです。なぜなら死はすべてを奪うので、*死なないこと* の価値は数学的に「キル1つ追加」の価値より高いからです。最も安全に登りたいなら、確実な離脱手段を持つクラスを選びましょう。Full Diamondへの最速到達を狙うなら、最初の3ファイトを確実に取れるクラスを選びましょう。

### ほとんどのプレイヤーが試すべき3クラスの軸

1. **Skirmisher** — バランスの取れた定番。短いトレード、素早い離脱、ミスを罰するのに十分なダメージ。
2. **Archer** — 序盤ラダーで最も安全。遠距離からアップグレードを稼ぎ、ターゲットのHPが削れてから初めて仕掛ける。
3. **Warrior** — すでにリードしているときの最適解。アーマー優位＋ブルーザーキットが、リードを連勝に変える。

決める前に、低リスクのロビーで3つすべてを試してください。クラスへの慣れはティアリストの理論に常に勝ります。

## エンチャント、パーク、Gear Saver：ロードアウトの層

クラス選択に加えて、ゲームはラン上にいくつかの進行システムを重ねています。エンチャントのロール、ゴールドで買うパーク、クレート、そしてケープです。これらは別個のビルドではなく、クラスの強みにかかる倍率として扱いましょう。

| システム | 何をするか | ビルドでの使い方 |
|---|---|---|
| Enchants | 装備に付くロール式の修飾効果 | 汎用ステータスではなく、クラスの勝ち筋に向けて再ロールする |
| Perks（ゴールド） | ラン中に購入するアップグレード | まず安定性、次に上限を買う |
| Crates | ランダム報酬 | ランとランの間に開ける。連勝中に気を散らさない |
| Capes | コスメティックコレクション | 好みで。登頂中に追う理由はない |
| Gear Saver | 高アップグレードでの死亡時にアーマーを保持 | Shadow以上まで取っておく。Ironで使うと無駄になる |

Gear Saverは**1 Upgrade Per Kill** で最も誤解されているアイテムです。高アップグレードで死んだときにしか意味を成さないため、正しいタイミングはごく狭い範囲に限られます。つまり、同じロビーでは現実的に作り直せない連勝を守るためのものなのです。早々に使ってしまうと、安全網がちょっとした便利アイテムに格下げされます。

エンチャントのロールにも同じ規律が必要です。すでに勝っているファイトを勝ちやすくする修飾効果は、負けているファイトから離脱しやすくする効果よりも価値が低いのです。ロールするときは、自分のビルドが実際に抱えている問題はどちらなのかを自問してください。

**1 Upgrade Per Kill** の連勝は予測可能な弧を描きます。スコアボードではなく、自分がいるフェーズを基準に判断を組み立てましょう。

| フェーズ | アップグレード範囲 | 主な目標 | 避けるべきこと |
|---|---|---|---|
| 序盤 | Leather → Copper | クリーンで低リスクなキル | 中央の争奪ファイト |

### 長期連勝と短命な連勝を分ける習慣

- **離脱手段があるときだけ戦う。** どうやって抜けるか言えないなら、そのファイトは始めない。
- **HPバーではなくアーマー差を見る。** 実アーマーの存在は、チップダメージの計画がバースト計画に負けやすいことを意味する。
- **リードしているときは高アップグレードのプレイヤーを狩る。** ボーナスXPは本物だが、逃げ道があるときだけその勝負に出る。
- **キルのたびにリセットする。** ノックバックとクリティカルのある自由参加型では、第三者は数秒で現れる。
- **Gear SaverはShadow以上まで取っておく。** 損失が本当に痛むのはそこだ。

## 1 Upgrade Per Killの最強ビルドを壊すミス

正しいクラスと正しいエンチャントを持っていても、プレイヤーはプロセスのミスで連勝を落とします。コミュニティから繰り返し報告されているのは以下のものです。

| ミス | なぜ悪いか | 対策 |
|---|---|---|
| 生存ではなくキルを狙う | 1回の死ですべてのアップグレードが消える | もう1キルよりも死なないことを重視する |
| Gear Saverを早く使う | 本当に必要なときに安全網がなくなる | Shadow以上まで取っておく |
| 連勝中にエンチャントを再ロールする | ファイト中に装備が不安定になる | ラン中ではなくランとランの間にロールする |
| XPインセンティブを無視する | 高アップグレードのプレイヤーは狩られる | Rubyに到達したら自分が標的だと想定する |
| セッションごとにクラスを変える | 離脱手段の筋肉記憶が育たない | 1セッションは1クラスに絞る |
| 開けた場所で戦う | ノックバックとクリティカルが悪い位置取りを罰する | 遮蔽物とチョークポイントを使う |

**1 Upgrade Per Kill** の最強ビルドとは隠された組み合わせではありません。使い慣れたクラス、勝ち筋に合ったエンチャント、温存しておいたGear Saver、そして何も得られないファイトから歩き去る規律——それだけです。

## コミュニティ報告とリーダーボード目標

ゲーム内リーダーボードはBest Streak、Top Kills、Fastest Diamondを記録しており、この3カテゴリは3つの異なるビルド哲学にきれいに対応します。Best Streakは生存優先のプレイを報います——機動力クラスと規律ある離脱です。Top Killsは攻撃性を報います——ファイトを素早く連鎖できるバーストクラスです。Fastest Diamondは特に序盤フェーズを報い、そこでは終盤のどんなエンチャントよりもクリーンな序盤のファイトが重要になります。

コミュニティ報告によれば、最速のDiamondランは絶えず乱闘するのではなく、少数の勝率の高いファイトだけを選ぶプレイヤーから生まれていますが、個々の結果はロビーによって変わります。新規プレイヤーは無料のスタートを活用できます。ゲーム説明には無料ギフト用のコード**WELCOME**が記載されており、さらにBlock PvPグループに参加すると追加報酬が得られます。こうした小さな先行アドバンテージはビルドを変えませんが、序盤フェーズを短縮してくれます。

特定のリーダーボードを狙うなら、そのリーダーボード向けにビルドしましょう。3つすべてを同時に制覇しようとしないでください——プレイスタイルが互いに逆方向に引っ張り合います。

## FAQ

**1 Upgrade Per Killで最強のビルドは何ですか？**
単一の固定された答えはありませんが、ほとんどのプレイヤーにとって最も安定する選択は、SkirmisherやArcherのような機動性の高いクラス、不利なファイトからの離脱を支えるエンチャント、そしてShadow以上まで温存したGear Saverです。1回の死がラダー全体をリセットするため、生存手段は純粋なダメージに勝ります。

**1 Upgrade Per Killで長期連勝に最適なクラスはどれですか？**
コミュニティ報告によれば、確実な離脱手段を持つクラスは一般に純粋なダメージクラスより長生きします。連勝重視のプレイヤーにはTricksterとSkirmisherがよく選ばれ、Warriorはすでにアーマー優位を握っているときに最も力を発揮します。

**Gear Saverは早めに使うべきですか？**
いいえ。高アップグレードでの死亡時にアーマーを保持するためのものなので、IronやCopperで使うとアイテムを無駄にします。装備を失うコストが最も大きいShadowやPrismまで取っておきましょう。

**Full Diamondへの到達を早めるには？**
LeatherからIronの間はファイトの数を絞ってクリーンに戦い、争奪の激しい中央エリアを避け、ターゲットがすでに弱っているときだけ仕掛けましょう。Fastest Diamondリーダーボードが評価するのは序盤フェーズの効率であり、総キル数ではありません。
