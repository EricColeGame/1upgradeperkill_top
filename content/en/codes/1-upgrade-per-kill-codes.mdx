## Fixing Common 1 Upgrade Per Kill Code Errors

Most "code not working" complaints trace back to four causes. Here is how to diagnose each one without guessing.

| Problem | Likely cause | Fix |
| --- | --- | --- |
| "Invalid code" response | Typo, wrong capitalization, or hidden space | Retype manually in all caps with no spaces |
| Code accepted but no reward | Already claimed on this account | Check inventory before assuming a bug |
| Code rejected outright | Expired or tied to a past update | Move on; watch official channels for the next drop |
| Menu will not open | Mid-round or server hiccup | Return to the lobby or rejoin the experience |

A gear reset after death is part of the arena's design, not a bug, and it is unrelated to code redemption. Do not confuse the two. If your upgrades vanished because you died, that is the game working as intended; if your code gift never arrived, that is a claim issue and worth a support check.

Community reports also flag one recurring mistake: players spam-submit the same code after a failure. Repeated submissions do not stack rewards. Once a code has been claimed on an account, it is spent — no matter how many times you press submit.

**Why does my 1 Upgrade Per Kill code say invalid?**

Nine times out of ten it is a formatting issue. Confirm every letter is capitalized, delete any leading or trailing spaces, and paste the code into the field rather than typing it from a screenshot. If it still fails, the code has likely expired or was already claimed on your account.

**Do codes give permanent upgrades?**

No. Code gifts sit outside the in-match upgrade ladder, and that ladder still resets when you die. Treat codes as a bonus on top of the normal loop, not a replacement for it.

**Can I redeem the same code on multiple accounts?**

Each account can claim a given code once, so a fresh account has its own claim available. Duplicate submissions on the same account will not grant a second gift.

Once a week is enough for most players. Codes are typically tied to updates and milestones rather than daily drops, so a quick check before each session keeps you current without wasting time.
